# 📘 Microcontroladores

Repositorio académico de la materia **Microcontroladores** (etapa disciplinaria, obligatoria) de la carrera de **Ingeniero en Computación**, UABC. Requisito: Organización y Arquitectura de Computadoras.

## 🎯 Propósito
Adquirir los conocimientos para diseñar e implementar sistemas digitales basados en microcontroladores, entendiendo la relación entre firmware (software especializado) y hardware digital en contextos de sistemas de tiempo real.

## 🎓 Competencia
Desarrollar el hardware y software de sistemas digitales basados en microcontroladores para aplicaciones de monitoreo, automatización y control de procesos, de forma analítica, propositiva y organizada.

## 🗂️ Unidades del curso
1. **Evolución de los microcontroladores** — Historia, sistemas embebidos, arquitectura, herramientas de desarrollo
2. **El microcontrolador** — Diagrama de bloques, CPU, organización de memoria, reloj y potencia, periféricos
3. **Conjunto de instrucciones** — Transferencia de datos, instrucciones aritméticas/lógicas, control de flujo, interrupciones
4. **Periféricos del microcontrolador** — GPIO, TIMER, USART, ADC/DAC, PWM, SPI/I2C/1-Wire/USB
5. **Desarrollo de aplicaciones** — Herramientas de firmware, arquitecturas típicas (ciclo ejecutivo, interrupciones, máquinas de estado, RTOS)

## 🧪 Prácticas
Talleres y laboratorios progresivos sobre cada periférico (GPIO, TIMERS, USART, ADC/DAC, PWM, I2C/1-Wire, SPI, USB), culminando en una **aplicación demostrativa** que integra la mayoría de los módulos de firmware desarrollados.

## 🏗️ Evidencia de desempeño
Biblioteca de módulos manejadores de los recursos del microcontrolador, con reporte de análisis, diseño, implementación y pruebas, más una aplicación demostrativa.

## 🛠️ Tecnologías
- Firmware en lenguaje de alto y bajo nivel (ensamblador/C)
- Tarjeta de desarrollo basada en microcontrolador
- Herramientas: compilador/ensamblador, encadenador, emulador de terminal
- Control de versiones: Git y GitHub
